# Avis-Enterprise-AI
Avis Enterprise AI is a full-stack enterprise knowledge assistant built with RAG, LangGraph, FastAPI, Amazon Bedrock, Pinecone, and PostgreSQL. It features document ingestion, conversational memory, AI guardrails, Human-in-the-Loop (HITL) approvals, observability, and automated AWS CI/CD deployment using Docker, Amazon ECR, EC2, and GitHub Actions.
